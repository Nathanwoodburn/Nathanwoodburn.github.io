# Self Hosting Updates

I haven't had to update much in my self hosting infrustructure. I moved data centres as my co-location provider closed down their Albury site. This move went smoothly and I haven't noticed any issues with the new data centre.
I've moved from using Purelymail as my main email service, I am now hosting pretty much all my emails using MailCow on my servers. I've also moved my VPN from Tailscale to NetBird which hasn't had many issues.

# NVim

I've recently started using neovim as my primary code editor. I still occasionally miss some parts of VS Code but editing files is often quicker using nvim now. I currently use NVChad as my configuration since it includes pretty much all I need and doesn't have much bloat.
