# Testing Coolify

I've been on uni break so have been playing around with various tools.

One of the main tools I've been looking at is [Coolify](https://coolify.io/) which is a self-hostable alternative to Vercel, Netlify etc. I've migrated a few sites that I was previously hosting directly on docker to use coolify. This allows the site to auto build when I push any changes to git.
