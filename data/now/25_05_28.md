# Proxy Pac Server

For people who want to use LetsDane or SANE without routing all their traffic through the proxy, I created a server that will serve a proxy pac file to only route Handshake domains through the user's local proxy.

Have a look at [https://pac.cn01.woodburn.au/](https://pac.cn01.woodburn.au/)

All the code is available here: [https://git.woodburn.au/nathanwoodburn/proxy-pac-server](https://git.woodburn.au/nathanwoodburn/proxy-pac-server)
