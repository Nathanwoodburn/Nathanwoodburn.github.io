# HNS Mastodon Instance

I've just setup a Mastodon instance that allows anyone to login with a Handshake domain using HNS Login. Check it out at [https://mastodon.hns.au](https://mastodon.hns.au)

# HNS Login Updates

I've updated HNS Login to use HIP13 data records to allow users to specify user info for the domain. I've also added Login using metamask and TXT records directly.
