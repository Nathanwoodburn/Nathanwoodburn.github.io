# New projects

In January I started building [FireWallet Browser](https://firewallet.au/). It is a web based wallet frontend for Handshake, built using python.

I also created [HNS Login](https://git.woodburn.au/nathanwoodburn/hns-login), [HNS Pay](https://git.woodburn.au/nathanwoodburn/hns-pay), [HNS Links](https://links.hns.au/) and [Site Manager](https://git.woodburn.au/nathanwoodburn/site-manager) in February.

In April I released [HNSDoH](https://hnsdoh.com) (a distributed DNS resolver).

In September I created a custom [HNSDoH status page](https://status.hnsdoh.com)

In October I created the [HS-Anyone](https://renew.hns.au) web application to allow for easy renewals of locked Handshake domains.

In December I created [Woodburn Vault](https://sol.woodburn.au), an index fund to allow people to invest into a diverse crypto portfolio
