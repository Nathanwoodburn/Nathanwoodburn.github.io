# Solana Blinks

I've been testing Solana Blinks or Actions. This allows you to have call to action buttons directly from a URL link. For example https://nathan.woodburn.au/donate should let you send me 0.01, 0.1 or 1 SOL with a single click. This currently is still in beta so you need to manually enable it in Phantom (or another SOL wallet) and it only shows the call to action buttons in twitter.
